# Foto 17 — Manual prático

Manual visual, responsivo e instalável para fotografar com o iPhone 17 normal. Funciona offline como PWA e é publicado pelo GitHub Pages.

## Conteúdo

- Guia de lentes 0,5x, 1x e 2x
- Receitas de dia, noite, retrato, macro, movimento, distância, selfie, comida e lua
- Camera Control, vídeos, ajustes, edição e solução de problemas
- Galeria de imagens fotográficas criadas especialmente para o manual

As informações técnicas se baseiam nas especificações e no Guia do Usuário oficiais da Apple. Projeto independente, não afiliado à Apple.
